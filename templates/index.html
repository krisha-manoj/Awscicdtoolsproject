AWS Tools Used

AWS CodeCommit

Managed Git repository hosting the application source code. Triggers the pipeline on every push to the main branch.

AWS CodeBuild

Fully managed build service that compiles the application, builds the Docker image, and pushes it to ECR.

Amazon ECR

Elastic Container Registry stores Docker images securely. Each build creates a new tagged image for deployment.

AWS CodeDeploy

Handles Blue/Green deployments to ECS. Routes traffic from the old version to the new version with zero downtime.

AWS CodePipeline

Orchestrates the entire CI/CD workflow — from source code change detection to production deployment.

Amazon ECS (Fargate)

Serverless container orchestration. Runs the application without managing servers. Scales automatically based on demand.

Application Stack

Python + Flask

Lightweight web framework serving the application. Simple MVC architecture with Jinja2 templates.

Gunicorn

Production-grade WSGI HTTP server running the Flask application inside the container.

Docker

Containerizes the application for consistent deployment across all environments.

Application Load Balancer

Distributes incoming traffic across containers. Supports Blue/Green deployment with two target groups.
